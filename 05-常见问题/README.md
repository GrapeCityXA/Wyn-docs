## 待成页清单

下面这些是高频问题，先列出来避免遗漏。写成页面后移到「已发布」表里并加链接——**不要提前放链接，死链比缺失更影响信任。**

### 产品与定位

- Wyn 和帆软 FineBI 有什么区别？
- Wyn 是 BI 工具还是报表工具？
- 已经用了 Excel，为什么还需要 BI？
- 支持国产数据库和信创环境吗？

### 部署与集成

- 能否嵌入到我自己的系统里，用户不用二次登录？
- 支持 Docker / 容器化部署吗？
- 能否只嵌入单个图表，而不是整页？
- 分析页面的样式能改成和自己产品一致吗？

### 数据与性能

- 支持连接哪些数据库？
- 数据量大时查询慢怎么办？
- 能否直接连数据仓库而不是先把数据复制过来？
- 支持实时数据吗，延迟多大？

### 报表

- 统计报表能导出 Excel 吗，格式会不会乱？
- 支持套打吗，能不能用现有的印刷单据？
- 报表的复杂表头和多级汇总能做吗？
- 报表能定时自动发给指定的人吗？

### 授权与服务

- 授权方式有哪些，怎么计价？
- 试用版有什么限制？
- 升级到新版本要额外付费吗？

## 新增问题的写法

新建 `q-<英文关键词>.md`，按下面的结构写。三条要求：

**一、首段直接给答案，加粗。** 不要「本文将介绍」，第一句话就要能独立成立。

**二、第二段再讲原因和细节。** 愿意往下读的人才是真正在做评估的人。

**三、相关链接指向具体页面**，不要指向目录。

判断是否值得单独成页的标准：**同一个问题被三个以上客户问到，或者它可能被搜索到。** 只被问过一次的内部疑问，记在清单里就行。
