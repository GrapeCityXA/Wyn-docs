# Wyn 商业智能 · 产品资料中心

Wyn 商业智能是基于葡萄城 20 多年数据分析技术积累打造的新一代嵌入式 BI 产品，提供多源数据整合、数据可视化、AI 对话式分析、在线报表设计、数据填报、嵌入式分析与系统管理等一站式数据分析能力。

本仓库面向客户与合作伙伴开放，内容按**「你要解决什么问题」**组织，而不是按源文件的格式（PPT / PDF / DOCX）组织。

## 写作与素材规范

新增或修改文档前，请先看 [文档模板](模板/doc-template.md)。三条硬性约定：

**1. 图片放在文档同级目录下的 `图片/`，不要集中堆到根目录。**

```
文档/02-行业方案/计量检测/
├─ README.md
└─ 图片/
   ├─ 01-painpoint-data-silos.png
   ├─ 02-architecture-overview.png
   └─ 03-dashboard-lab-ops.png
```

引用写法：`![数据分散的四个来源](./图片/01-painpoint-data-silos.png)`

这样单篇文档是自包含的，搬运、删除或交接都不会产生断链。

**注意：目录名用中文，文件名仍然用英文。** 目录名是给人在 GitHub 上浏览时看的，中文更亲切；文件名如果也用中文，在部分工具链、URL 和 CI 脚本里会遇到编码问题。图片、脚本、配置文件的名称一律保持英文小写加连字符。

全站共用的 logo、图标放根目录 [静态资源](静态资源/)。

**2. 图片文件名 = 章节号 + 主题 + 序号，全小写英文加连字符。**

不要用 `image1.png`、`截图 2026-08-11 下午4点22分.png`。按文件名排序时，图片顺序就应该等于阅读顺序。

**3. 图片统一压缩为 PNG，不要转 JPG。**

BI 截图的主体是表格和文字，JPG 压缩会让文字边缘发毛，客户看不清数字。用 PNG 量化压缩（视觉无损，体积通常降到 1/3 到 1/2）：

```bash
python 脚本/compress_images.py 文档/
```

批量执行前先 `git commit`，脚本会原地覆盖文件。加上 `--check` 只做规范检查不压缩。

```bash

```
