# Wyn 商业智能 · 产品资料中心

Wyn 商业智能是基于葡萄城 20 多年数据分析技术积累打造的新一代嵌入式 BI 产品，提供多源数据整合、数据可视化、AI 对话式分析、在线报表设计、统计报表、数据填报、嵌入式分析与系统管理等一站式数据分析能力。

这里汇集 Wyn 的产品说明、行业方案、部署指南与常见问题，面向客户与合作伙伴开放。内容按**「你要解决什么问题」**组织，你可以从下面对应自己的角色找到入口。
