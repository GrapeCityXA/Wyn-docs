# 快速上手

## 五分钟跑通一个仪表板

1. **安装或访问环境** —— 使用试用环境，或按[部署文档](../04-部署运维/README.md)在自有服务器安装
2. **连接数据源** —— 添加数据库连接，或直接上传一份 Excel
3. **创建数据集** —— 选择表，拖入需要的字段，必要时加计算字段
4. **新建仪表板** —— 拖入图表组件，绑定字段，选择图表类型
5. **预览与分享** —— 调整布局后发布，设置访问权限
