# 客户案例

每个案例一个文件，结构统一：背景 → 问题 → 方案 → 效果 → 客户评价。

## 写作要求

**必须有可公开的效果数据。** 没有数据的案例读起来像宣传稿，客户不会信。「查询响应从 30 秒降到 3 秒」「月度报表耗时从 3 天缩短到 2 小时」这类具体对比，比十句形容词有用。

**写清实施边界。** 用了哪些数据源、接了几个系统、实施周期多长、谁参与。读者是在评估自己的项目能不能做成，这些信息决定了他的判断。

**客户名称的公开须经确认。** 未获授权时用行业 + 规模描述（「某大型医药流通企业」），不要写真实名称。
