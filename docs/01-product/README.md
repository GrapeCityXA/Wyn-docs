# 产品能力概览

Wyn 商业智能在一个平台上覆盖「数据接入 → 分析设计 → 消费分发 → 嵌入集成」的完整链路，企业无需为报表、大屏、填报、AI 问数分别采购不同工具。

## 五个能力域

| 能力域 | 解决什么问题 | 详细文档 |
| --- | --- | --- |
| 多源数据整合 | 数据散落在 ERP、MES、LIMS、Excel 中，无法统一查看 | 见下方「数据整合」 |
| 数据可视化 | 需要仪表板、大屏、移动端看同一份数据 | [可视化与仪表板](visualization/README.md) |
| AI 对话式分析 | 业务人员不会拖拽建模，希望直接问问题拿结果 | [AI 问数](ai-analytics/README.md) |
| 在线报表与填报 | 数据要能在线录入、审核、回写，而不是靠邮件收 Excel | [数据填报](data-entry/README.md) |
| 嵌入式分析 | 自有产品需要内置分析能力，不想让用户跳转到外部系统 | [嵌入式集成](embedded/README.md) |

## 数据整合

Wyn 支持直连主流关系型数据库、数据仓库、大数据平台与 API 数据源，也可对接 Excel 与 CSV。数据集层支持建模、计算字段、参数与权限过滤，业务用户在设计层看到的是已建模的语义层，不需要理解底层表结构。

> 具体支持的数据源清单随版本更新，请以官方在线文档为准，参见[帮助文档导航](../03-getting-started/README.md)。
