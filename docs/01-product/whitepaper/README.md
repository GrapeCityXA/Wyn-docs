# 产品白皮书

> 本页对应《Wyn 商业智能软件产品白皮书 V9.0 Update1》。完整 PDF 见[下载说明](../../../downloads/README.md)。

白皮书拆成章节独立成页，是为了让其中某一章可以被单独引用、单独检索。选型阶段的沟通里经常需要把「技术架构」这一章直接发出去，而不是让客户在 40 页 PDF 里翻找。

## 章节规划

## 拆分原则

保持三条：

**一、每章开头一句结论，能脱离上下文独立成立。** 比如「Wyn 采用前后端分离架构，前端为纯浏览器渲染，服务端支持 Windows 与 Linux 双平台部署」。这句话单独被引用时也成立。

**二、白皮书原图的编号保留。** 图 3-2 仍然是图 3-2，方便客户拿着 PDF 与网页对照。

**三、原文不改写。** 白皮书是正式对外文件，措辞经过审核，拆分时只做排版适配，不调整表述。需要通俗解释的部分放到各能力域文档里，不回改白皮书。

## 图片处理

白皮书插图按章节落到本目录 `images/`，命名 `fig-图号-主题.png`：

```
images/
├─ fig-2-1-deployment-topology.png
├─ fig-3-1-dataset-model.png
└─ fig-4-2-iframe-embedding.png
```

从 PDF 提取图片有两条路：`pdftoppm` 按页导出后裁切，或用 Acrobat 的导出功能。宽度 1200–1600px 足够 2 倍屏显示，再大只是浪费体积。

## 拆分顺序建议

先拆「技术架构」和「集成与嵌入」两章。这两章被单独索取的频率最高，拆完立刻能用。产品定位一章与[产品能力概览](../README.md)内容有重叠，建议最后做，避免同一段话维护两份。
