# 行业解决方案

BI 项目失败的常见原因不是工具不行，而是没贴着行业实际业务做。这里按行业整理完整方案，每个方案都从该行业真实的痛点出发，说明数据怎么打通、分析什么、交付成什么形态。

## 行业列表

| 行业 | 核心场景 | 方案 |
| --- | --- | --- |
| 制造业 | 生产运营、质量、供应链、仓储、经营分析 | [制造业数字化解决方案](制造业/README.md) |
| 计量检测 | 实验室运营驾驶舱、检测周期、设备效能、质量趋势 | [计量检测数字化解决方案](计量检测/README.md) |

## 一个方案包含什么

每个行业方案的页面结构一致，方便你按同样路径了解不同行业：

- **行业痛点** —— 这个行业在数据与决策上的具体困境，而不是泛泛的「数字化转型」
- **方案结构** —— 从数据源到消费端的分层设计
- **典型应用场景** —— 具体分析什么、关注哪些指标、带来什么价值
- **与既有系统的关系** —— 要不要替换现有系统、须不须改造
- **交付形态** —— 嵌入、独立门户还是大屏

## 需要的行业还没覆盖

目前提供制造业与计量检测两个行业。其他行业的需求可以联系葡萄城获取针对性的方案沟通，或查阅[官方解决方案库](https://www.grapecity.com.cn/solutions/wyn)。
