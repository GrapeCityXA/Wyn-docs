# 数据可视化、仪表板与大屏

Wyn 的可视化层解决一个具体问题：**同一份数据，管理层想看大屏、业务想看仪表板、外勤想看手机，不用做三套。** 设计一次，多端自适应。

## 三层产物

| 形态 | 典型用途 | 设计要点 |
| --- | --- | --- |
| 仪表板 | 日常分析、钻取、联动、自助探索 | 交互丰富，支持参数与筛选器联动 |
| 数据大屏 | 指挥中心、展厅、会议室 | 固定分辨率、强视觉、弱交互 |
| 移动端 | 外勤、巡检、随时查看 | 布局自适应，核心指标优先 |

## 组件能力

覆盖常规图表（柱线饼散、雷达、瀑布、甘特等）、地图（含地理编码与多层下钻）、KPI 卡片、明细表与透视表，以及 3D 场景化组件用于数字孪生类展示。

每个组件都支持一致的交互配置：联动、跳转、钻取、提示标签、条件格式、空值处理、无数据样式。这套一致性比单个组件的华丽程度更重要——客户在项目里 80% 的时间花在配置交互，而不在于选哪个图表。

## 设计侧的效率设计

- **主题与样式复用**：企业视觉规范一次定义，全站统一
- **组件布局**：栅格 + 自由布局双模式，大屏用自由布局，仪表板用栅格
- **数据交互可视化配置**：联动、跳转不写代码
- **AI 辅助生成**：用自然语言生成初版图表，再手工调整

## 素材建议

本目录 `图片/` 下放产品截图与典型成品示例。截图时有两点直接影响客户的观感：

1. **用真实业务数据，不要用「示例1/示例2/123」。** 截图里的数字越像真的，客户越容易代入自己的场景。
2. **统一截图宽度与浏览器缩放。** 混着不同 DPI 的截图放在同一页，视觉上很廉价。建议统一 1440px 宽、100% 缩放。
