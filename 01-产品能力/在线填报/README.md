# 在线数据填报

企业里有一类数据永远进不了系统：月度经营目标、预算调整、门店巡检记录、项目进度说明。它们在 Excel 里，通过邮件和微信群流转，最后由一个人手工汇总。Wyn 填报要解决的就是这一段。

核心设计是**保留 Excel 的操作体验**：用过 Excel 的人打开就能填，不需要培训。但数据落在数据库里，带权限、带流程、带校验，填完立刻能进入分析。

## 为什么不是「再买一个表单工具」

表单工具能收数据，但收完的数据是孤立的。Wyn 填报的关键差别在于**填与分析同平台**：

- 填报模板可以直接引用已有数据集，带出上期值、目标值、同比参考
- 提交后数据直接进入分析模型，不需要导出再导入
- 审批流通过后可触发下游报表刷新

这个闭环省掉的是「收表 → 汇总 → 导库 → 做报表」中间的人工环节，也是数据错漏的主要来源。

## 典型场景

| 场景 | 填报内容 | 后续分析 |
| --- | --- | --- |
| 月度经营目标 | 各部门目标值、实际值、偏差说明 | 目标达成率、偏差归因 |
| 预算编制与调整 | 科目、期间、金额、调整原因 | 预算执行对比 |
| 门店 / 产线巡检 | 检查项、结果、照片、异常描述 | 巡检合格率、问题分布 |
| 项目进度上报 | 里程碑、完成度、风险 | 项目健康度 |
| 数据补录 | 系统外产生的历史数据 | 补齐历史趋势 |

## 能力要点

- **Excel 式编辑**：类 Excel 的单元格操作、公式、格式、复制粘贴
- **数据校验**：必填、类型、范围、唯一性、跨字段逻辑校验
- **权限控制**：按组织、角色控制可填范围与可见字段
- **提交流程**：提交、退回、审核、归档，支持多级
- **数据回写**：提交结果写入指定数据表
- **模板分发**：按角色下发不同填报模板
