# 统计报表

统计报表解决的是仪表板解决不了的那类需求：**格式固定、要打印、要签字盖章、要按监管模板导出。** 财务月报、经营分析表、监管报送表、生产日報，这些报表的版式有硬性规定，一个单元格都不能挪，图表拼不出来，必须用报表工具。

## 统计报表和仪表板的分工

这是客户最容易混淆的地方，也是选型时最该先讲清的一点。

| 维度 | 统计报表 | 仪表板 |
| --- | --- | --- |
| 版式 | 固定，严格对齐，行列位置不可变 | 灵活，组件可自由排布 |
| 主要读者 | 财务、经营、监管、审计 | 管理层、业务分析人员 |
| 核心诉求 | 数据准确、格式合规、可打印可导出 | 快速洞察、交互探索 |
| 典型产物 | 月度经营表、财务报表、报送表 | 运营驾驶舱、分析看板 |
| 交互 | 少，主要是参数查询与钻取 | 多，联动、筛选、下钻 |
| 输出 | Excel / PDF / 打印 | 屏幕浏览、大屏 |

两者不是替代关系。真实项目里通常是**同一个数据底座，两种消费形态**：数据在数据集层统一，仪表板给管理层看趋势，统计报表给财务出正式文件。

## 设计体验

采用类 Excel 的设计界面，用过 Excel 的人可以直接上手：

- 单元格级操作：合并、边框、字体、对齐、数字格式、条件格式
- 拖拽绑定数据字段到单元格，支持明细、分组、聚合
- 公式与表达式：支持聚合函数、数学、字符串、日期、逻辑与自定义表达式
- 表头支持多层嵌套，适合中国式报表的复杂表头结构
- 支持交叉表（行维度 × 列维度动态扩展）

对从 Excel 迁移过来的客户，这一点很关键：**不需要重新学一套设计逻辑，只需要理解「数据从哪来」和「参数怎么传」。**

## 关键能力

**复杂表头与版式控制。** 多级表头、跨行跨列合并、固定行列、页眉页脚、页码、打印区域设定。报表的版式精度直接决定能否通过审计与归档。

**参数与查询。** 支持参数化查询，按时间、组织、产品等条件动态取数。参数可配置默认值与联动，避免用户每次重新选择。

**套打与打印。** 支持套打模板，用于已有印刷单据的场景（如检测报告、出库单、票据）。可精确控制打印位置、边距与纸张规格。

**导出。** 支持导出 Excel、PDF、Word 与图片。导出的 Excel 保留公式与格式，不是截图贴图——这点在财务场景里是硬要求。

**定时推送。** 报表可按计划生成并推送到指定人员，替代「每月初人工导出再发邮件」的流程。

**权限与数据范围。** 与平台统一的权限体系打通，同一张报表按角色与组织过滤数据，不同分公司的人打开只能看到自己的数据。

## 典型场景

| 行业 | 报表类型 | 关键要求 |
| --- | --- | --- |
| 财务 | 资产负债表、利润表、现金流量表 | 格式严格、可审计、导出 Excel |
| 经营 | 月度经营分析表、部门考核表 | 多级表头、分组汇总 |
| 制造 | 生产日报、工时统计、质量报表 | 按班次/产线汇总、套打 |
| 计量检测 | 检测报告、委托单、原始记录 | 套打、按模板输出 PDF |
| 监管 | 行业报送表、统计年报 | 格式固定、按期提交 |

## 与填报的关系

报表和填报经常在同一个业务流程里出现，但职责不同：

- **报表**是读出：从数据源取数、按格式呈现、输出与打印
- **填报**是写入：在线录入、校验、审批、回写数据库

典型组合是「填报采集 + 报表输出」：各部门用填报提交月度数据，汇总后用统计报表生成正式的经营分析表。参见[在线填报](../在线填报/README.md)。

## 素材建议

本目录 `图片/` 下放报表设计界面与成品截图。两类截图必须各有一张：

1. **设计态截图** —— 展示类 Excel 的编辑界面与字段拖拽，让客户看到上手成本低
2. **成品截图** —— 展示一张真实的复杂表头报表，证明版式能力到位

报表截图最容易犯的错误是**只截设计器不截成品**。客户真正判断的是「能不能做出我要的那张表」，而不是设计器长什么样。
