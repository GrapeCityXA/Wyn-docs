# 产品能力概览

Wyn 商业智能在一个平台上覆盖「数据接入 → 分析设计 → 消费分发 → 嵌入集成」的完整链路，企业无需为图表分析、统计报表、大屏、填报、AI 问数分别采购不同工具。

## 五个能力域

| 能力域 | 解决什么问题 | 详细文档 |
| --- | --- | --- |
| 多源数据整合 | 数据散落在 ERP、MES、LIMS、Excel 中，无法统一查看 | 见下方「数据整合」 |
| 数据可视化 | 需要仪表板、大屏、移动端看同一份数据 | [可视化与大屏](可视化与大屏/README.md) |
| 统计报表 | 要出格式固定、可打印可导出的正式报表 | [统计报表](统计报表/README.md) |
| AI 对话式分析 | 业务人员不会拖拽建模，希望直接问问题拿结果 | [AI 问数](AI问数/README.md) |
| 在线数据填报 | 数据要能在线录入、审核、回写，而不是靠邮件收 Excel | [在线填报](在线填报/README.md) |
| 嵌入式分析 | 自有产品需要内置分析能力，不想让用户跳转到外部系统 | [嵌入式集成](嵌入式集成/README.md) |

## 三种分析形态怎么选

「我到底该用哪个」是选型时最常遇到的困惑。判断依据是**产物形态**，不是数据量：

| 你要的产物 | 用哪个 | 说明 |
| --- | --- | --- |
| 看趋势、找问题、交互探索 | [可视化与大屏](可视化与大屏/README.md) | 图表组合，可筛选、联动、钻取 |
| 出正式文件、要打印签字、格式不能变 | [统计报表](统计报表/README.md) | 类 Excel 设计，严格版式，可套打 |
| 让不会建模的人自己问问题 | [AI 问数](AI问数/README.md) | 自然语言直接取数出图 |
| 把数据收上来 | [在线填报](在线填报/README.md) | Excel 式录入、校验、审批、回写 |
| 嵌到自己的产品里 | [嵌入式集成](嵌入式集成/README.md) | API 嵌入、单点登录、权限传递 |

多数企业最终会同时用到其中三到四种，同一份数据在不同场景下呈现为不同形态。

## 数据整合

Wyn 支持直连主流关系型数据库、数据仓库、大数据平台与 API 数据源，也可对接 Excel 与 CSV。数据集层支持建模、计算字段、参数与权限过滤，业务用户在设计层看到的是已建模的语义层，不需要理解底层表结构。

数据整合是所有上层能力的共同底座：仪表板、统计报表、AI 问数、填报都建在同一套数据集上，指标口径只需要定义一次。

> 具体支持的数据源清单随版本更新，请以官方在线文档为准，参见[帮助文档导航](../03-快速上手/README.md)。
