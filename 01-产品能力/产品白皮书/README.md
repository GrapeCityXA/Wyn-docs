## 白皮书与在线文档的分工

白皮书是**整体材料**，适合一次通读、建立概念框架，或者作为立项、评审的附件。

官方帮助文档是**查阅材料**，适合解决具体操作问题，且始终跟随产品版本更新，见[帮助文档导航](../../03-快速上手/README.md)。

遇到「这个产品能不能做某某事」这类具体判断，看在线文档更准；要做整体评估或方案汇报，白皮书更合适。
