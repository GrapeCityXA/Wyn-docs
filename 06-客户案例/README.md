# 客户案例

真实项目里，客户最关心的不是功能列表，而是「和我情况类似的企业，用成了什么样」。这里按行业整理已落地的案例，每个案例都包含背景、方案与可量化的效果。

## 智慧交通

某城市交通管理部门需要把分散在多个业务系统中的设施状态、交通运行数据汇聚起来，做统一的监测与应急响应。

Wyn 整合设施健康状态与交通运行数据，对接并提升现有业务应用系统，在可视化大屏上搭载 3D 模型呈现路网与设施，支持动态交互式分析。管理人员从「事后调取报表」转为「实时掌握路网状态」，应急响应速度明显提升。

## 医药流通

某医药流通云服务商希望在自己的 SaaS 产品中内置数据分析能力，让下游客户在平台内直接看经营数据，而不必跳转到另一个系统。

Wyn 的嵌入式能力与云平台深度集成，分析页面直接呈现在业务系统内，用户无需二次登录。平台侧实现了从「客户自己导数据到 Excel」到「在线实时洞察」的转变，也把数据分析变成了产品的一项增值能力。
