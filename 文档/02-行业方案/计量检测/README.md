# 计量检测行业数字化运营解决方案

计量检测机构普遍已经建成 LIMS，但管理层仍然拿不到能支撑决策的数据。Wyn 的做法不是替换 LIMS，而是在 LIMS 之上补一层分析能力：把分散在各业务系统里的数据汇聚成统一视图，让实验室的运营状态从「月底看报表」变成「随时可查」。

> 完整方案 PPT 见[下载说明](../../../下载/README.md)，本页是可检索、可引用的文字版。

## 为什么 LIMS 建好了，管理还是很困难

这是方案要回答的第一个问题。三类典型困境：

**数据分散，没有统一视图。** LIMS 管业务流程，ERP 管财务与人财物，设备系统管仪器状态，物联网平台管环境与能耗，此外还有大量 Excel 在各部门手里流转。每套系统都只回答自己那一段，跨系统的问题——比如「某个检测项目从接单到出具报告的周期为什么变长」——没有任何一个系统能直接回答。

**缺少运营驾驶舱。** 数据要靠人工汇总，出一次月度经营分析要几个人对表格对三四天，等报表出来，问题已经发生完了。

**分析滞后于业务。** 报告进度、设备利用率、人员负荷、超期预警这些需要天级甚至小时级关注的指标，停留在月报节奏上，管理动作永远慢一拍。

## 方案结构

*（示意图位 → `图片/01-architecture-overview.png`，待从 PPT 导出：数据源层 → 数据整合层 → 分析应用层 → 消费端）*

方案分四层：

1. **数据汇聚** —— 对接 LIMS、ERP、设备系统、物联网平台与 Excel，形成统一数据源
2. **指标建模** —— 把业务口径固化为可复用的指标定义，避免各部门各算一套
3. **分析应用** —— 运营驾驶舱、专题分析、填报采集
4. **交付形态** —— 嵌入现有业务系统 / 独立门户 / 大屏

## 典型应用场景

| 场景 | 关注指标 | 价值 |
| --- | --- | --- |
| 实验室运营驾驶舱 | 委托单量、在检任务、报告及时率、超期预警 | 管理层一屏掌握整体运营状态 |
| 检测周期分析 | 各环节耗时、瓶颈工序、异常单占比 | 定位周期变长的真实原因 |
| 设备与人员效能 | 设备利用率、校准到期提醒、人均产出 | 优化资源配置，避免设备闲置与超期 |
| 质量趋势分析 | 不合格率、复检率、项目趋势 | 提前发现质量风险 |
| 数据填报补录 | 线下数据在线采集、审核、回写 | 消除 Excel 邮件往来 |

## 与 LIMS 的关系

这是客户最常问的问题，需要明确说清：**Wyn 不替代 LIMS，也不要求改造 LIMS。**

- LIMS 继续管业务流的发起、审批与归档，它是记录系统（system of record）
- Wyn 从 LIMS 只读取数据，不写入业务表，不改变 LIMS 的运行逻辑
- 分析结果通过嵌入方式回显到 LIMS 界面里，用户不需要切换系统

对接方式通常是直连 LIMS 数据库的只读视图，或通过 LIMS 提供的 API 取数。前者实施快，后者在 LIMS 数据库结构不稳定时更可靠。

## 交付形态

针对检测机构的实际情况，方案支持三种交付形态：

**嵌入现有系统。** 通过 API 把仪表板嵌入 LIMS 或门户，用户在原系统里就看到分析结果。适合已经习惯现有系统、不希望增加新入口的机构。

**独立分析门户。** 给管理层与分析岗一个独立入口，与业务系统解耦，迭代不受 LIMS 版本牵制。

**大屏。** 实验室大厅、会议室的大屏，用于日常运营看板与对外展示。
