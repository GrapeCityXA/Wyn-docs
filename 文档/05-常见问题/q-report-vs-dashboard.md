# 统计报表和仪表板有什么区别，我该用哪个？

**按产物判断：要出正式文件、要打印签字、格式一个格子都不能动，用统计报表；要看趋势、找问题、上下钻取，用仪表板。** 多数企业两个都要，它们不是替代关系。

## 核心差别

| 维度 | 统计报表 | 仪表板 |
| --- | --- | --- |
| 版式 | 固定，严格对齐行列位置 | 灵活，组件可自由排布 |
| 主要读者 | 财务、经营、监管、审计 | 管理层、业务分析人员 |
| 核心诉求 | 数据准确、格式合规、可归档 | 快速洞察、交互探索 |
| 典型产物 | 月度经营表、财务报表、报送表 | 运营驾驶舱、分析看板 |
| 交互 | 少，主要是参数查询 | 多，联动、筛选、下钻 |
| 输出 | Excel / PDF / 打印 | 屏幕浏览、大屏 |

## 一个容易混淆的点

「数据量大就要用报表工具」是错的。数据量决定的是数据层的设计（是否走聚合表、要不要抽取），和用报表还是仪表板无关。仪表板同样可以承载千万级数据，统计报表也照样能跑小表。

真正的分界线只有一条：**看的人要不要一张能签字的纸。**

## 实际项目里的组合

真实项目通常长这样：

- 数据在数据集层统一建模，指标口径只定义一次
- 仪表板给管理层看经营趋势、给业务看日常状态
- 统计报表给财务出月度正式报表、给监管报送
- 填报采集基层数据，报表输出汇总结果

同一份数据、同一套权限，只是消费形态不同。这也是为什么建议在一个平台上做，而不是买一个 BI 再加一个报表工具——两个工具意味着两套数据模型、两套权限、两份维护成本。
