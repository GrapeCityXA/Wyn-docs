# Wyn 可以私有化部署吗？

**可以，而且是完整功能的私有化部署，不是削减版。** Wyn 安装在企业自有服务器上，支持完全内网、离线环境运行，数据不经过任何外部服务。

## 这意味着什么

部署在自有环境后：

- 数据从源系统到分析结果全程留在内网，不产生外部传输
- 用户认证可以对接企业的 AD / LDAP / 单点登录
- 版本升级由企业自己安排节奏，不强制跟随云端更新

对金融、医疗、检测认证这类对数据边界有硬要求的行业，这一点通常是选型的先决条件，而不是加分项。

## 部署形态

单机、应用与数据分离、集群三种形态都支持，Windows 与 Linux 双平台，也支持容器化。具体选哪种取决于并发用户数与可用性要求，参见[部署与运维](../04-部署运维/README.md)。

## 需要注意的前提

私有化部署不等于装上就能用，两件事需要提前确认：

**离线环境的授权激活。** 完全断网的环境需要走离线授权流程，实施前先和商务确认授权文件的获取方式，不要等到部署当天才发现。

**内网数据源连通性。** Wyn 服务器到各业务数据库之间的网络策略要提前开通。这是实施阶段最常见的阻塞点，属于网络侧工作，不是产品问题。
